# fonts/ — шрифты и конвертеры CamBrowser

Инструментальная папка проекта: исходные шрифты, генератор битмап-глифов 8×8
и обёртка официального LVGL-конвертера. **В сборку прошивки не входит** —
ESP-IDF компилирует только `main/` и `components/`.

## Состав

| Файл | Назначение |
|------|-----------|
| `psf/Cyr_a8x8.psfu` | **основной источник** — рукотворный консольный шрифт 8×8 с кириллицей (пакет `kbd`, kernel.org); его метрики совпадают со встроенным ASCII-шрифтом проекта |
| `psf/LatArCyrHeb-08.psfu` | альтернативный 8×8 (Latin-Arabic-Cyrillic-Hebrew), держится для справки |
| `gen_cyr_from_psf.py` | конвертер PSF2 → таблица `app_overlay_font8x8_cyr[66][8]` (Python, без зависимостей) |
| `cyr_font_table.c` | эталонный вывод конвертера |
| `ttf/DejaVuSansMono*.ttf` | TTF для LVGL-конвертера (для битмапа 8×8 TTF **не** использовать — замыливает ш/ж/щ) |
| `lvgl_convert.sh` | конвертация TTF → C-шрифт формата LVGL через `npx lv_font_conv` |

## Почему не TTF

Первая версия кириллицы рендерилась из DejaVu Sans Mono в 8 px автоматически
(Pillow): сложные буквы — ш, щ, ж, л, д — слипались в нечитаемые пятна.
8×8-кириллица должна быть нарисована вручную; `Cyr_a8x8` — классический
консольный шрифт, который десятилетиями использовался во FreeBSD/Linux.
Его сетка совпадает со встроенным ASCII-шрифтом проекта:
прописные строки 0–6, строчные 2–6, хвосты (р, у, д, ц, щ, ф) до 7.

Ё/ё в cp866-шрифте нет — конвертер собирает их из Е/е + точки в строке 0
(так же, как краткая у Й/й расположена в самом шрифте).

## Перегенерация таблицы

```bash
cd fonts
python3 gen_cyr_from_psf.py        # таблица -> cyr_font_table.c + ASCII-превью
```

Затем перенести массив `app_overlay_font8x8_cyr` в `main/app_overlay.c`
и собрать прошивку (`idf.py build`). Точечные правки отдельных букв —
в словаре `OVERRIDES` внутри конвертера (ASCII-арт).

Лицензия исходного шрифта: GPL-2.0+ (пакет kbd, шрифты LatArCyrHeb/Cyr —
автор Dmitry Yu. Bolkhovityanov и др.); атрибуция сохранена в шапке
таблицы и здесь.

## LVGL-шрифт (векторный, если понадобится)

Для крупного сглаженного текста (LVGL v8/v9):

```bash
cd fonts
./lvgl_convert.sh ttf/DejaVuSansMono.ttf 16 lv_font_mono_16.c
```

Диапазоны символов в скрипте: ASCII `0x20–0x7F`, `Ё/ё`, `А..я`.
Требуется Node.js/npm — `npx` сам скачает `lv_font_conv` при первом запуске.
Полученный `lv_font_*.c` добавляется в LVGL-проект как обычный `lv_font_t`.

## Добавить другой шрифт

- Битмап 8×8: положите `.psfu`/`.psf` в `fonts/psf/` и укажите путь в
  `SRC` конвертера (юникод-таблица разбирается автоматически).
- LVGL: любой TTF в `fonts/ttf/` первым параметром `lvgl_convert.sh`.
  Кириллицу поддерживают DejaVu, Liberation (`/usr/share/fonts/truetype/liberation/`),
  FreeSans/FreeSerif/FreeMono.
