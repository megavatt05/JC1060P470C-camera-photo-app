# Wi‑Fi менеджер CamBrowser

**Ветка:** `feature/wifi-c6`

## Возможности

1. **Список сетей** — скан на экране «Wi‑Fi»
2. **SoftAP портал** — сеть `CamBrowser-Setup` (открытая), страница  
   `http://192.168.4.1:8080/` — ввод SSID/пароля
3. **NVS** — namespace `wifi_mgr`, ключи `ssid` / `pass`
4. **Тест интернета** — HTTP `generate_204` + `speed_test` (Мбит/с)

## Экран LCD

Кнопка **Wi‑Fi** на домашнем экране →  
Скан · Подключить (сохранённая) · Портал · Тест сети

## Порты HTTP

| URL | Назначение |
|-----|------------|
| `http://<STA_IP>/log` | логи |
| `http://<STA_IP>/speed` | история speed |
| `http://192.168.4.1:8080/` | портал настройки (SoftAP) |

Портал на **8080**, чтобы не конфликтовать с log_server на 80.
