# Тест скорости сети (перед фильмом)

**Ветка:** `feature/wifi-c6`

## Что делает

Перед стартом видео плата скачивает ~512 КБ с `speed.cloudflare.com` и считает **Мбит/с** на активном интерфейсе (Ethernet или Wi-Fi).

| Скорость | Вердикт |
|----------|---------|
| < 0.5 Мбит/с | плохо — стрим будет рваться |
| 0.5…2 Мбит/с | норм для профиля smooth (320×180) |
| > 2 Мбит/с | хорошо |

## Где смотреть

- **Serial** — строки `speed_test: результат: …`
- **HTTP** — `http://<IP_платы>/speed` (HTML, история до 8 замеров в RAM)
- **Логи** — `http://<IP_платы>/log` (кольцо 20 КБ)

История только в RAM (перезагрузка очищает).

## API

```c
speed_result_t r;
if (speed_test_run(&r) == ESP_OK) {
    // r.mbps, r.iface_str, r.note
}
```
