Терминал COM — cambrowser

Живой просмотр журнала платы через Web Serial (как монитор порта в Arduino IDE). Логи копируются одной кнопкой — пришлите их ассистенту для анализа.

отключено
Этот браузер не поддерживает Web Serial. Откройте файл в Google Chrome или Microsoft Edge на ПК. Firefox и мобильные браузеры не подходят.
Скорость 115200 8N1 (прошивка использует стандартный вывод IDF). Плата держит порт, пока открыта эта страница; если плата уже занята другим приложением — закройте его. Перед прошивкой терминал нужно отключить (кнопка «Отключить» появляется вместо «Подключить»).
