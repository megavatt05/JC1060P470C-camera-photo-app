# Прошивка ESP32-P4 через COM-порт — полная инструкция

Плата: **JC1060P470C** (ESP32-P4, 1024×600, Ethernet IP101)
Прошивка: **cambrowser 7ab5082** — браузер + видео + ФИЛЬМЫ + friendly-интерфейс v2 + фикс SD/LDO.

## Короткая памятка (TL;DR)

> Подключить плату кабелем USB-C → открыть `web_flasher_cambrowser.html` в Chrome/Edge →
> нажать «ПОДКЛЮЧИТЬ И ПРОШИТЬ» → выбрать COM10 → ждать 1–3 минуты → плата сама перезагрузится.
> Галочку «Erase device» не ставить. Всё.

---

## 1. Что понадобится

- Плата JC1060P470C и **кабель USB-C с передачей данных** (не «зарядный»!)
- ПК с Windows 10/11 и браузером **Chrome** или **Edge** (Firefox и мобильные не умеют Web Serial)
- Интернет при первом открытии формы (библиотека флешера грузится с CDN; сама прошивка уже внутри страницы)

## 2. Подключение платы

1. Вставьте кабель USB-C в разъём питания/связи платы, второй конец — в ПК.
2. Откройте **Диспетчер устройств → Порты (COM и LPT)**: должен появиться
   `USB Serial Device (COM10)` (для штатного USB-Serial-JTAG драйвер в Windows уже встроен).
3. Если используете внешний переходник CH340/CP210x и порта нет — установите драйвер
   (CH340: search «CH341SER»; CP210x: «CP210x VCP» у Silicon Labs).
4. Плата в обычном режиме НЕ требует перевода в загрузчик — флешер сбросит её сам.
   Если соединение не ловится: см. раздел 7 (режим загрузки вручную).

## 3. Способ 1 — веб-форма (рекомендуется)

1. Откройте форму: локальный файл `web_flasher_cambrowser.html` (двойной клик)
   или прямая ссылка GitHub Pages (см. README комплекта).
2. Нажмите **«ПОДКЛЮЧИТЬ И ПРОШИТЬ»** → в окне браузера выберите COM10.
3. В диалоге флешера **не включайте** «Erase device» (сохранятся закладки браузера)
   → INSTALL.
4. Прогресс: Подключение → Загрузчик → Запись 3 разделов (~2,4 МБ) → Проверка → Reboot.
5. После перезагрузки на экране появится браузер.

## 4. Способ 2 — ESP Launchpad (официальный веб-инструмент)

1. Откройте https://espressif.github.io/esp-launchpad/ в Chrome/Edge.
2. CONNECT → COM10 → вкладка **Flash** → Add File:
   `cambrowser_p4_7ab5082_full.bin`, адрес **0x0** → FLASH.

## 5. Способ 3 — flash_COM10.bat (без браузера)

Двойной клик по `flash_COM10.bat` (нужен Python 3.9+; esptool поставится сам).
Заливает bootloader 0x2000, partition-table 0x10000, приложение 0x20000 и перезапускает плату.

## 6. Способ 4 — esptool вручную

```
esptool --chip esp32p4 --port COM10 --baud 921600 write_flash ^
  0x2000 bins\bootloader\bootloader.bin ^
  0x10000 bins\partition_table\partition-table.bin ^
  0x20000 bins\cambrowser.bin
```

## 7. Если что-то пошло не так

| Симптом | Решение |
|---|---|
| COM10 не появляется | Другой кабель (data-кабель), другой USB-порт, поставить драйвер CH340/CP210x |
| Флешер не может подключиться | Режим загрузки вручную: зажать **BOOT**, нажать и отпустить **RESET**, отпустить **BOOT**, повторить прошивку |
| Ошибка записи на середине | Снизить скорость: в .bat заменить 921600 на 460800; не использовать USB-хаб |
| Порт занят | Закрать Arduino IDE / другой монитор порта, который держит COM10 |
| Плата зависла после прошивки | Зажать BOOT, RESET; прошить ещё раз с галочкой Erase device (сбросит настройки) |

## 8. Альтернативные варианты подключения

| Вариант | Как | Когда полезно |
|---|---|---|
| **USB-Serial-JTAG (COM10)** — основной | USB-C разъём платы | В 99% случаев; драйверов не нужно |
| **USB-OTG (native USB CDC)** | Если на плате второй USB-C — воткнуть в него; появится ещё один COM-порт, esptool/web-форма работают так же | Основной разъём сломан |
| **Внешний USB-UART адаптер** | CH340/CP2102: **U0TXD→RXD адаптера, U0RXD→TXD, GND→GND**; в загрузчик: BOOT→GND и RESET | USB-порты платы неисправны |
| **Flash Download Tool (GUI)** | flash-download-tool с espressif.com: chip = ESP32-P4, файлы и адреса как в способе 4, режим UART | Не хочется ни браузера, ни Python |
| **WSL2 + usbipd-win** | `usbipd bind`/`attach --wsl`, внутри WSL esptool --port /dev/ttyUSB0 | Прошивка из Linux-окружения на Windows-ПК |
| **OTA по Ethernet** (перспектива) | Плата сама обновится по HTTP из своей сети — можно добавить в приложение как функцию | Устройство уже смонтировано, USB недоступен |
| **Автообновление с SD-карты** (перспектива) | Приложение при старте ищет на SD файл обновления и применяет | Полевое обновление без ПК |

## 9. Справка: адреса разделов

| Раздел | Адрес | Размер | Назначение |
|---|---|---|---|
| bootloader | 0x2000 | 24 КБ | Загрузчик (flash 16MB, dio) |
| partition-table | 0x10000 | 3 КБ | Таблица разделов |
| nvs | 0x11000 | 24 КБ | Настройки (флешером не трогается) |
| factory (app) | 0x20000 | 7 МБ | Приложение cambrowser |

## 10. Проверка после прошивки

1. Экран загрузился, есть Ethernet (IP 192.168.1.106), страницы открываются.
2. **ФИЛЬМЫ** → GO (пустой запрос = популярное) → запустить фильм (советуем «Night of the Living Dead»).
3. Тап по фильму в High-profile → должно показаться сообщение о непдерживаемом формате, а не перезагрузка.
4. Видео до конца → выход в меню → повторный запуск видео — без краша (фикс ab3950a).
5. Свои фильмы: `convert_movie.bat` (320×180, Baseline) → SD-карта → папка SD в браузере.
